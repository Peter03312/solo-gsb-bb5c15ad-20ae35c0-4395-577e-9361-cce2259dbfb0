# Hamilton 最大余数席位分配悖论核查工具

帮助编辑核查**阿拉巴马悖论**（Alabama paradox）、**人口悖论**（population paradox）与
**新增地区席位扰动**的 Web 应用，全部计算基于 `fractions.Fraction` 精确分数与整数交叉相乘，**不使用浮点或舍入值判定**。

## 功能

### 模式一：阿拉巴马悖论扫描

- 录入若干地区的正整数人口与席位总数起止值，系统用 Hamilton 法（最大余数法）逐个席位总数计算配额、整数席位与余数
- 自动扫描并**高亮每一次阿拉巴马悖论**（总席位增加一个后，某地区反而失去席位），变化前后结果并列展示（精确分数、余数排序、席位归属）
- 扫描跨度限制：**终止值 − 起始值 ≤ 500**
- 内置可复现示例，一键载入

### 模式二：人口悖论分析

- 为**同一组地区**录入前后两期正整数人口与**固定总席位**，两期分别沿用同一套精确 Hamilton 规则分配
- 增长比 = 后期人口 ÷ 前期人口，以精确分数表示；大小比较一律用**整数交叉相乘**（`后期A × 前期B` 与 `后期B × 前期A`），不使用浮点或舍入值
- 对每个减席地区与每个增席地区两两检查：**减席地区增长比严格更高**时记录为异常组合，并附交叉相乘的两个整数乘积作为可复核证据
- 页面并列展示两期人口、精确增长比（分数 + 小数展示值）、两期席位与变化量，高亮悖论涉及的减席 / 增席地区，并附两期完整 Hamilton 分配明细
- 内置可复现示例，一键载入

### 模式三：新增地区席位扰动

- 录入原有地区正整数人口、基准总席位，以及**一个新增地区**的人口与新增席位扫描区间（**终止值 − 起始值 ≤ 50**）
- 对扫描区间内每个新增席位数 k：先按现有精确 Hamilton 规则对原地区计算**一次**基准分配（基准总席位），再将新增地区并入人口列表，以 **基准席位 + k** 为总席位重新分配
- 逐档列出所有原地区相对基准分配的席位变化；**仅当原地区之间同时出现减席者与增席者**时标记为扰动事件（新增地区自身席位不计入判定；只减不增、只增不减、全部不变均不算）
- 每个扰动事件并列展示基准分配与并入重分配的两次精确配额、余数排名与席位归属，并单独给出新增地区本档所得席位
- 页面另以逐档总览表展示每个新增席位数下全部地区（含新增地区）的最终席位与原地区变化
- 内置可复现示例，一键载入

### 通用规则

- 决胜规则：余数较大者优先 → 人口较多者优先 → 录入顺序较早者优先
- 配额、余数与增长比均以精确分数计算与展示（小数仅为展示用、由整数运算精确舍入到 6 位）

## 快速启动（Docker，一条命令）

```bash
docker compose up --build
```

启动后访问：**http://localhost:8000**

页面顶部切换「阿拉巴马悖论扫描」「人口悖论分析」「新增地区席位扰动」三种模式。

如需更换宿主机端口（例如 9000）：

```bash
HOST_PORT=9000 docker compose up --build
```

然后访问 http://localhost:9000 。

## 本地开发（不用 Docker）

```bash
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

访问 http://localhost:8000 。运行测试：`python -m pytest tests/`。

## 配置

| 配置项 | 方式 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 宿主机访问端口 | 环境变量 `HOST_PORT` | `8000` | 仅 docker compose 启动时生效 |
| 扫描跨度上限 | `app/main.py` 中 `MAX_SPAN` | `500` | 阿拉巴马扫描终止值 − 起始值的最大值 |
| 新增席位扫描跨度上限 | `app/main.py` 中 `MAX_EXTRA_SPAN` | `50` | 新增席位终止值 − 起始值的最大值 |
| 地区数量上限 | `app/main.py` 中 `MAX_REGIONS` | `100` | 单次请求最多地区数 |

## 内置可复现示例

### 阿拉巴马悖论示例

点击「阿拉巴马悖论扫描」模式下的「载入可复现示例」或调用 `GET /api/example`：

| 地区 | 人口 |
| --- | --- |
| 甲区 | 44 |
| 乙区 | 43 |
| 丙区 | 7 |
| 丁区 | 6 |

扫描范围 8 ~ 14（总人口 100）。在总席位 **10 → 11** 时触发悖论：

- 总席位 10：配额 22/5、43/10、7/10、3/5 → 席位 **4、4、1、1**
- 总席位 11：配额 121/25、473/100、77/100、33/50 → 席位 **5、5、1、0**

丁区由 1 席降为 0 席——总席位增加，它反而失去一席，即阿拉巴马悖论。

### 人口悖论示例

点击「人口悖论分析」模式下的「载入可复现示例」或调用 `GET /api/population-example`：

| 地区 | 前期人口 | 后期人口 | 增长比 |
| --- | --- | --- | --- |
| 甲区 | 11 | 15 | 15/11 ≈ 1.3636 |
| 乙区 | 31 | 36 | 36/31 ≈ 1.1613 |
| 丙区 | 14 | 16 | 8/7 ≈ 1.1429 |

固定总席位 **10**（前期总人口 56，后期总人口 67）：

- 前期分配：配额 55/28、155/28、5/2 → 席位 **2、6、2**
- 后期分配：配额 150/67、360/67、160/67 → 席位 **2、5、3**

乙区增长比 36/31 **高于**丙区 8/7（整数交叉相乘验证：36×14 = **504** > **496** = 16×31），
但总席位不变时乙区反而由 6 席降为 5 席、丙区由 2 席升为 3 席——即人口悖论。

### 新增地区席位扰动示例

点击「新增地区席位扰动」模式下的「载入可复现示例」或调用 `GET /api/disturbance-example`：

原地区：

| 地区 | 人口 |
| --- | --- |
| 甲区 | 111 |
| 乙区 | 197 |
| 丙区 | 319 |

基准总席位 **9**（原地区总人口 627）；新增地区「丁区」人口 **132**，新增席位扫描 1 ~ 5。

基准分配：配额 333/209、591/209、87/19（余数 124/209、173/209、11/19 = 121/209，余数排名 乙 > 甲 > 丙）→ 席位 **2、3、4**。

仅在**新增 2 席**（总席位 11，总人口 759）时构成扰动事件：

- 并入后配额：甲 37/23、乙 197/69、丙 319/69、丁 44/23
- 余数排名（统一分母 69）：丁 63/69 > 乙 59/69 > 丙 43/69 > 甲 42/69，3 个余数席位归丁、乙、丙
- 并入后席位 **甲 1、乙 3、丙 5、丁 2**：甲区由 2 席降为 1 席（减席），丙区由 4 席升为 5 席（增席），乙区不变

减席与增席同时在**原地区之间**出现（新增地区丁区自身得 2 席，不计入判定），标记为扰动。
其余档位：新增 1 席时仅甲区减席（席位 1、3、4、2）；新增 3 ~ 5 席时原地区只持平或增席——均不构成扰动。

## API

### `POST /api/scan`

阿拉巴马悖论扫描。请求体：

```json
{
  "regions": [{"name": "甲区", "population": 44}, {"name": "乙区", "population": 43}],
  "start": 8,
  "end": 14
}
```

返回每个总席位数的完整分配结果（配额/余数的精确分数与小数展示值、余数排名、席位归属）以及 `paradoxes` 列表（每次悖论的 `from_seats`、`to_seats` 与失去席位的地区）。

### `POST /api/population`

人口悖论分析。请求体：

```json
{
  "regions": [
    {"name": "甲区", "population_before": 11, "population_after": 15},
    {"name": "乙区", "population_before": 31, "population_after": 36},
    {"name": "丙区", "population_before": 14, "population_after": 16}
  ],
  "seats": 10
}
```

返回：

- `rows`：每个地区的两期人口、精确增长比（`growth_str` 分数 / `growth_decimal` 小数展示值）、两期席位与变化量 `delta`
- `before` / `after`：两期各自的完整 Hamilton 分配结果（与 `/api/scan` 单行结构相同）
- `anomalies`：每组「减席地区增长比严格高于增席地区」的异常组合，含 `loser`、`gainer` 及交叉相乘证据 `cross_loser`、`cross_gainer`（整数乘积，以字符串传输以免大数精度丢失）

### `POST /api/disturbance`

新增地区席位扰动分析。请求体：

```json
{
  "regions": [
    {"name": "甲区", "population": 111},
    {"name": "乙区", "population": 197},
    {"name": "丙区", "population": 319}
  ],
  "base_seats": 9,
  "new_region_name": "丁区",
  "new_region_population": 132,
  "extra_start": 1,
  "extra_end": 5
}
```

约束：`extra_end >= extra_start` 且跨度不超过 50；新增地区名称不能与原地区重复；`base_seats + extra_end` 不超过席位上限。返回：

- `baseline`：原地区按基准总席位的 Hamilton 分配（只计算一次，各档共用）
- `results`：逐档（每个新增席位数）的并入重分配完整结果，含 `extra_seats`、`seats_total`、
  全部地区（含新增地区）的配额/余数字段、`new_region_seats`、原地区逐区 `deltas`、
  `losers` / `gainers` 与 `is_disturbance`（原地区中减席与增席同时存在才为 `true`）
- `disturbances`：所有扰动档的 `extra_seats`、`seats_total` 及对应减席 / 增席地区名单

### `GET /api/example`

返回阿拉巴马悖论内置示例输入，可直接作为 `/api/scan` 的请求体。

### `GET /api/population-example`

返回人口悖论内置示例输入，可直接作为 `/api/population` 的请求体。

### `GET /api/disturbance-example`

返回新增地区席位扰动内置示例输入，可直接作为 `/api/disturbance` 的请求体。

### `GET /api/health`

健康检查，返回 `{"status": "ok"}`。
